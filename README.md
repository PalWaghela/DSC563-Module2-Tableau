# DSC 563 – Module 1 and Module 2

## Project Overview
This project compares a Python visualization with a Tableau
visualization using simulated community workshop attendance data.

## Module 1
- Python visualization
- Data preparation
- Claim verification
- Simulated data documentation

## Module 2
- Tableau attendance visualization
- Python and Tableau value comparison
- Monthly utilization analysis
- Capacity-weighted utilization
- Independent East neighborhood verification

## Data Note
The dataset is simulated and does not represent actual
community workshop observations.
